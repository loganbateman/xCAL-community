# OTK Tony Kart baseline draft

This draft is based on the **dry setup** in the supplied *OTK Chassis - Set Up
Guide*. It is bundled as an editable template. Each team sees it in **Parts →
Baseline Setups** until that team reviews and saves its own copy.

| xCAL field | Draft value |
|---|---|
| Top Pill Position | FWD (Arrow forward) |
| Bottom Pill Position | FWD (Arrow forward) |
| Front Left Camber | 0 ticks |
| Front Right Camber | 0 ticks |
| Toe | half box toe-out (1mm) |
| Front Torsion Bar | Flat OTK |
| Front Ride Height | MID (middle height) |
| Ackerman | BOTTOM HOLE |
| Axle | N 1030 mm |
| Rear Ride Height | MID (middle height) |
| Front Spacers | 1 large spacer (15mm) |
| Front Hub Type | Standard OTK hubs |
| Rear Track Width | 54 3/4 - 55 1/8 |
| Rear Hub Type | Standard OTK hubs |
| Front Rims | OTK MXJ |
| Rear Rims | OTK MXJ |
| Clutch Slip | 9500-10400 RPM |
| Carburetor | Pop (8-12 psi) Fulc (.045-.055 in) |
| Needle Settings | L 2 1/4 - 2 3/4 H 1/8 - 1/2 |
| Flex Length | 7 3/4- 8 1/2 in |
| Exhaust Pipe | L2 |
| Oil Mix | 8 oz per gallon |
| Fuel | 110 Race Fuel |

The guide also specifies no rear torsion bar and one supplementary seat stay on
each side. xCAL has no standard fields for those items, so they are retained in
the template notes. Seat position varies with driver height. Tire pressures,
temperatures, gearing, carburetor settings, and other unspecified values remain
blank rather than being guessed.

The saved record is a universal, team-owned baseline and can be edited like any
other baseline. It deliberately requires no driver, kart, or track selection.
