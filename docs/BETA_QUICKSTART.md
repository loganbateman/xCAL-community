# xCAL Community quick start

## Install

Download the Windows installer from [Releases](https://github.com/loganbateman/xCAL-community/releases), run it, and open **xCAL Community** from the Start menu.

For the portable ZIP, extract the entire folder and open **xCAL Community.exe**. Keep the accompanying files beside it.

No Python or configuration files are needed. This is an unsigned beta, so Windows or Google may display a warning. If access is blocked, contact the maintainer with the message shown.

## Sign in and choose a team

Sign in with Google, then choose your team or create one. For this beta, use a dedicated test folder.

Invited teammates accept Google's sharing email and sign in with the same Google account. Refresh the team list if needed. There are no invitation codes.

[Team setup and invitations](GOOGLE_DRIVE_SETUP.md)

## Everyday use

- Start a setup from a baseline or a previous setup.
- Run 1 is your baseline; later runs keep their own changes and notes.
- Save your work. It stays on this device and syncs while the app is open.
- Check pending work in the Sync Queue.
- Customize fields, maintenance checks and part types in **Settings > Workspace**.
- Export or restore backups under **Settings > Workspace > Backups**.

## Updates

Open **Settings > Workspace > Updates**. Older previews may need a manual installer update.

Community installs separately from regular xCAL. If an older installation shared regular xCAL's folder, install version 0.2.2 or newer without running the old shared-folder uninstaller first.

[Report a problem](https://github.com/loganbateman/xCAL-community/issues)
