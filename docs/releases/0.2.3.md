# xCAL Community 0.2.3

- Delete custom setup fields without a restore area.
- Baseline templates show just the setup, without run logs or checklists.
- Removed the prefilled OTK notes; your own notes stay unchanged.
- Open your team's Google Drive folder with a simple link.
- Clearer sign-in messages and shorter setup help. No configuration files are needed for users.

Download the Windows installer below, or use **Settings > Workspace > Updates**.
Community installs separately from regular xCAL.

This remains an unsigned beta. Google sign-in availability depends on the project's approval and access limits.
